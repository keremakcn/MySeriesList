# MySeriesList identity

- Master: `static/branding/series-watchlist-logo.png` (transparent PNG).
- UI asset: `static/branding/series-watchlist-256.png`.
- Windows icon: `static/branding/series-watchlist.ico`, with 16, 20, 24, 32, 40, 48, 64, 128 and 256 px frames.
- Created using the built-in image generation tool. Pillow was used only for size/format conversion; the generated artwork and alpha were retained.
- Concept: lavender bookmark ribbon, S-shaped fold and play symbol on a charcoal tile, matching the existing interface.

## Original generation prompt

Use case: logo-brand. Create one polished production app icon / standalone logo mark for MySeriesList, a private TV series journal desktop application. Square 1024x1024 canvas. A single centered distinctive bold lavender ribbon bookmark folded into a softly angular S silhouette, with a small crisp dark triangular play cutout integrated into the upper ribbon; subtly suggests stacked TV episodes and saving a story. Strong simple geometry, thick broad strokes readable at 24px, balanced negative space. Mark inside a deep charcoal (#171922) rounded-square app tile with generous but compact margins, tile occupies 92% of canvas. Lavender #c8bbff with restrained violet shading on one fold only. Premium calm contemporary editorial feel. Flat vector-like precision, no thin lines, no filmstrip perforations, no television antenna, no letters or words, no watermark, no mockup scene, no external drop shadow, no decorative stars. True transparent pixels outside rounded-square tile. Deliver only the one icon, front-facing, perfectly square, no presentation board.
